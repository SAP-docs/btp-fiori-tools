# Make Adaptations

You can make adaptations to the adaptation project, including adapting the UI and adding app descriptor changes.



> ### Note:  
> SAP Fiori Elements-based apps can be additionally adapted using the possibilities described in [Extending Delivered Apps Using Adaptation Extensions](https://ui5.sap.com/#/topic/52fc48b479314d0688be24f699778c47).
